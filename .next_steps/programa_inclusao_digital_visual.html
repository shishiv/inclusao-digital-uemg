Capacitados (histórico)

No ciclo PAEx 2025, o projeto foi modernizado com portal web funcional, 9 aulas construídas do zero, exercícios interativos e metodologia andragógica documentada. Os alunos compareciam semanalmente por iniciativa própria — sinal claro de engajamento. Os temas incluíram segurança online, redes sociais, ambiente Google, serviços governamentais (INSS, Receita Federal, Gov.br) e PIX.

Estrutura de Trilhas

O programa amplia o escopo: de um projeto focado no 60+ para um programa abrangente de inclusão digital para todas as idades. A trilha 60+ permanece como âncora com 16 anos de credibilidade, e novas trilhas atendem demandas emergentes.

Trilha âncora
Inclusão Digital 60+
Adultos 50+ e terceira idade
Fundamentos digitais, comunicação, redes sociais, Gov.br, INSS, Receita Federal, PIX, segurança online. 16 anos de execução validada.

Palestras com Convidados
Comunidade acadêmica e externa
Temas variados conforme expertise dos convidados: cibersegurança, programação, marketing digital, novas tecnologias.
Oportunidade institucional — GitHub Student Developer Pack: A UEMG pode articular acesso ao GitHub Education para todos os seus alunos, garantindo acesso gratuito a GitHub Copilot, modelos frontier de IA (GPT, Claude), créditos de cloud (Azure, AWS), ferramentas de desenvolvimento profissional e domínios gratuitos. Isso posiciona os estudantes da UEMG em pé de igualdade com alunos de universidades federais e privadas de referência — e o programa de Inclusão Digital pode ser o veículo para difundir esse acesso.
O Gargalo: Produção de Conteúdo

A experiência de Frutal revelou que o maior desafio não é executar as aulas — é produzir materiais didáticos, programáticos e visuais de qualidade para múltiplos públicos e temas. Um único bolsista tem capacidade limitada para criar artes, roteiros, exercícios e conteúdo acessível.

A rede resolve isso

Com múltiplas unidades contribuindo, o acervo cresce de forma colaborativa. A multidisciplinaridade da UEMG é o motor: Design cria artes, Computação desenvolve conteúdo de IA, Administração produz módulos de produtividade. Cada unidade que adere é uma produtora de conteúdo para toda a rede.
